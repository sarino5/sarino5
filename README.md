# 👋 Hi there ![](https://komarev.com/ghpvc/?username=sarino5&color=d93b7d)

I'm a data scientist working across analytics engineering and AI engineering. At TelevisaUnivision I co-maintain the Customer Data Profile, a dbt pipeline on BigQuery that unifies 50M+ accounts. I also build LLM applications and pipelines, with the evaluations that keep them reliable. Before that, I was a product data scientist at LinkedIn, running A/B tests and building metrics for job-seeker features. I'm finishing an M.S. in Computer Science at Georgia Tech, and I enjoy turning messy data into products and decisions that move the business. Feel free to explore my repositories, and reach out if you'd like to collaborate.
